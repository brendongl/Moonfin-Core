   matched inbound Emby `POST /Sessions/.../Playing/Stop` requests from the
   provider's internal `host1`, user agent `axios/1.13.6`. Client tracing
   independently identified the remote Playstate handler as the stop caller.
   The sender/policy remains unidentified. Do not classify this as a decoder
   crash or bypass remote Stop. The 1080p copy played continuously with subtitles.

   non-admin Emby service account authenticates to Emby, but Seerr rejects it
   with HTTP401. Provider account synchronization/access is required. The relay
   is deliberately diagnosis-only; no live issue was submitted.
3. **Missing-source player-to-Seerr acceptance is missing evidence.** The old
   missing-file fixture now returns metadata404. Unit tests and earlier fixture
   UI checks are not substitutes for the full live acceptance gate.
