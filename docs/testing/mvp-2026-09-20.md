## Reproduced and repaired

Max29 was running 2.4.0-sipflix.21 and failed Bluey S3E24 with HTTP 500.
The server received `h264-profile=none` and could not match an H264 encoder.
The native codec probe now seeds a conservative AVC profile before invoking the
platform, bounds each native request, preserves the fallback after legacy calls,
and retries failed capability detection without blocking launch. The same
transcoded episode played on Max29 with the replacement build; Shield played it
via DirectPlay.

Other repairs in this change:

- Show preflight/loading state immediately; reject stale preflight results before
  they can overwrite the bitrate of a newer playback session.
- Keep playback errors visible with remote-accessible retry/back/connection
  controls. Stop a native startup after 60 seconds without playback/first frame.
- Keep buffering from triggering the screensaver; keep deferred player focus
  requests from taking focus away from dialogs and failure controls.
- Accumulate consecutive hidden-OSD seeks correctly, lift native subtitles above
  controls, and make timeline focus and controls legible over bright video.
- Preserve the remembered home row during transient focus loss; honor book sort
  choices; scope fallback recommendations to visible libraries; expire library
  count summaries; deduplicate cast; skip inert cast cards; support additional
  activation keys; reuse marquee measurements and handle loading-logo failure.

Scrolling card titles remain the existing design. Server-provided numeric
SortName values remain metadata, not an app sorting defect.

## Limits

Two reachable devices and selected real titles do not establish universal codec,
server, live-TV or device compatibility. Muted playback tests establish rendered
video/subtitles and player state, not subjective audio quality. The existing focus-recovery behavior can still consume the first directional
press; its guard remains because removing it previously broke home navigation.
This is an MVP candidate for a small pilot, not a claim that every historical
minor UI issue is eliminated. Retain a rollback APK for any customer pilot.
